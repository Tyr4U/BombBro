# BOMBBRO
Team Lead / Technical Gameplay Designer  
Unreal Engine 5 | 2025–Present

Play the build: https://access-none.itch.io/bombbro

## What players do
Run, punch, roll, and use bomb abilities to fight enemies and reach BossBot.

## My work
- Led a 4-person team
- Built core systems, block-mesh prototypes, and combat/traversal encounters
- Lighting and player abilities (bombs, mortar, dash/roll)
- Iterated from playtest feedback and published the itch.io build

This repo holds project files. The playable game is on itch.io.
